# Emmanuel Kagodo — Personal Website

Professional portfolio for Emmanuel Kagodo, a Ugandan battery and e-mobility practitioner, data scientist, renewable-energy researcher and educator.

## Focus

- Battery engineering, diagnostics and second-life storage
- Electric mobility systems and technical training
- Mini-grid intelligence, dashboards and reporting automation
- Renewable-energy research, MEAL and carbon markets
- Technical education and applied writing

## Technology

The site is intentionally lightweight:

- Semantic HTML5
- Modern responsive CSS
- Dependency-free JavaScript
- GitHub Pages hosting

No build process, framework, analytics tracker or API key is required.

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Accessibility and performance

The site includes keyboard navigation, a skip link, reduced-motion support, responsive navigation, descriptive metadata and structured data. The existing portrait remains in the repository as `profile.jpg`.

## Deployment

GitHub Pages serves the `main` branch. Changes should be reviewed in a branch before merging.
